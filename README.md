# Lua Synopsis

My personal Lua 5.4 documentation with runnable examples.

## Structure

- `_G_functions/` — global functions
- `standard_libraries/` — standard libraries
- `syntax/` — patterns, operators, metamethods
- `_G_list.lua` — full list of globals

## Usage

Uncomment the example code you want to run, then execute the file:

```bash
lua file.lua
```

## Requirements

Lua 5.4
